# Общий код

Сюда уезжает всё, чем пользуются и internal, и external: крипта, сетевой протокол,
математика, утилиты, работа с лаунчером.

Библиотека `shadow_shared` сейчас header-only (`INTERFACE`). Когда появятся `.cpp`,
переведите её в `STATIC` и поменяйте `INTERFACE` на `PUBLIC` в `target_*` вызовах.

## Важно

Правки здесь затрагивают оба продукта сразу. Не меняйте `shared/` из веток `internal`
или `external` — заведите отдельную ветку `shared/<что-меняем>` и PR в `dev`,
иначе второй разработчик получит конфликт или сломанную сборку на своей стороне.
