# Каркас проекта

Архив прежней ветки `dev`. Здесь остались отдельные цели CMake для internal и external, общий заголовочный код и папки-заглушки лаунчера и сайта.

Реализации компонентов находятся в ветках `components/*`. Ссылки на них — в [основном README](https://github.com/alexkweppas-beep/shadowcheat-portfolio).

Флаг `SHADOW_DEV_BUILD` управляет диагностикой каркаса. В ветках компонентов настройки сборки отличаются, их нужно смотреть отдельно.
